## Isi Umum Tiap File
Setiap README modul berisi:
- lokasi file view
- tujuan modul
- fitur utama
- daftar tab
- cara penggunaan per bagian
- catatan implementasi

## Kegunaan Folder Ini
Dokumen-dokumen di folder ini cocok dipakai untuk:
- panduan user internal
- handover ke tim backend
- referensi QA/UAT
- dokumentasi sebelum integrasi API

## Referensi Tambahan
- Untuk desain tabel backend per modul, lihat folder `../rencana-tabel-modul/`.
- Untuk versi gabungan semua modul, lihat file `../rencana_tabel_modul_view.txt`.
